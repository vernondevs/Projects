## Архитектура

```
shared/            общий код клиента и сервера (TypeScript)
  constants.ts     размеры тайлов, тик сервера, лимиты
  map.ts           генератор карты (детерминированный, по seed)
  formulas.ts      характеристики, урон, опыт
  classes.ts       классы персонажей
  skills.ts        дерево умений
  items.ts         базовые предметы, редкость, генерация лута
  mobs.ts          мобы и боссы
  protocol.ts      типы сообщений клиент <-> сервер
server/src/
  index.ts         HTTP + WebSocket, раздача собранного клиента
  db.ts            SQLite (node:sqlite), аккаунты и сохранения
  rooms/WorldRoom.ts   комната мира: вход, сообщения, игровой цикл
  rooms/schema.ts      синхронизируемое состояние (позиции, HP, анимации)
  game/            логика: Player, Mob, бой, умения, ИИ, боссы, лут
client/
  index.html, src/main.ts
  src/scenes/      Boot (загрузка), Login, Game
  src/ui/          HUD, инвентарь, персонаж, умения, чат, торговец (DOM)
  public/assets/   спрайты, тайлы, иконки (генерируются tools/gen-assets.ts)
tools/gen-assets.ts  генератор оригинального пиксель-арта 32×32 в PNG
tests/bots.ts        боты: вход, движение, чат, бой, лут, сохранение
tests/screenshot.ts  скриншоты клиента через Chrome
```

Принципы:
- Сервер авторитарен: клиент шлёт только намерения (направление движения, цель, умение). Скорость, дистанция, перезарядка, мана, инвентарь и цены проверяются на сервере.
- Публичное состояние (позиции, HP, анимации) идёт через Colyseus Schema. Личное (инвентарь, статы, опыт) уходит отдельным сообщением только владельцу.
- Одноразовые события (урон, снаряды, эффекты, телеграфы боссов) идут пакетом `fx` раз в тик.

## Карта

Мир 1100×360 тайлов (data/world.json, shared/map.ts), потолок уровня 100.
- Аурелион (запад) — столица Сольгарда; Мортхейм (восток) — столица Умбрата; между ними ~3,5 мин пешком.
- В середине: нейтральные города Эмберхолл, Оазис, Снежная долина (бой запрещён, стража бьёт нарушителя).
- PvP: фракции враждуют везде вне городов; в столицах защитники бьют чужака; арена и замки — отдельно.
- 12 новых зон, дороги, реки с мостами, 18 поселений (деревни, лагеря, руины, места встреч), 9 указателей.
- Боссы: Древний Энт, Болотная Ведьма, Повелитель Пепла и др. (data/world.json → bosses); данж Пепельные чертоги.
- Старые зоны (холмы, лес, топи) — уровни пересчитаны, см. data/world.json.

## Этапы

1. Структура и план. Зависимости, конфиги, общий код.
2. Сервер и движение. Комната мира, вход по имени и паролю, SQLite, карта, синхронизация игроков, чат. Проверка: боты видят друг друга.
3. Бой. Мобы с ИИ, автоатака, 4 умения на класс с перезарядкой и маной, смерть и возрождение. Проверка: бот убивает моба.
4. Прокачка. Опыт, уровни до 100 (BALANCE.md), очки характеристик, дерево умений с пассивками.
5. Лут. Редкость, инвентарь, экипировка, зелья, торговец.
6. Боссы. Три босса с фазами, телеграфами атак и уникальным лутом.
7. Графика и полировка. Пиксель-арт, анимации ходьбы, атаки и смерти, частицы, цифры урона, мини-карта.
8. README, CREDITS, финальная проверка.

9. PvP-арена 1×1 и 2×2 с рейтингом и сезонами — готово.
10. Боты на арене (через 45 с ожидания, без рейтинга) — готово, `server/src/arena/bots.ts`.
11. Сниженный PvP-урон (`PVP_DAMAGE_MULT` в shared/arena.ts) — готово.
12. Прямая торговля между игроками — готово, `server/src/trade/`, `client/src/ui/trade.ts`.

После каждого этапа: `npm run typecheck`, `npm test` (боты) и скриншот клиента.
