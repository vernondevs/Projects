# Бэклог

Этапы переносятся в PLAN.md по порядку, после завершения предыдущего.

## Этап 2. Мир (после него расставляется весь контент)

- [ ] 47. Расширение карты под фракции и новые уровни — core-engineer. (Включает старую задачу 34: большая карта и особенности городов.)
  - Новые зоны до максимального уровня, пересчёт уровней мобов в старых зонах. Подводных локаций нет — все локации реалистичные (подводная бухта из биомов убрана).
  - Два стартовых города на разных краях карты: столица Сольгарда (светлый камень, золотые купола, знамёна с солнцем) и столица Умбрата (тёмный камень, шпили, кости, пурпурные огни, туман) — по стилю из FACTIONS.md. Нейтральные города между ними. Спорные PvP-зоны на границе фракций.
  - Большие расстояния (между городами несколько минут пешком): деревни, лагеря мобов, руины, мосты, перекрёстки с указателями, места встреч; загрузка чанками.
  - Уникальные особенности городов, торговцы, квесты, NPC, стиль и музыка; телепорты после первого визита пешком.
- [ ] 48. Система путешествий — feature-dev. Открываемые точки перемещения, возврат в выбранное поселение, понятный маршрут. Цена от уровня. Туман над неисследованными территориями. Точки перемещения врагов недоступны.
- [ ] 49. Логово Повелителя пепла — feature-dev. Разместить на новой карте. Вход через ворота, которые нужно разбить (у ворот HP). Снизить скорость появления мобов перед воротами, чтобы комнату можно было зачистить.
- [ ] 50. Мировой босс — feature-dev. Место на новой карте (желательно в спорной зоне), появление по расписанию, объявление заранее, требует нескольких игроков.
- [ ] 51. Возрождение с перезарядкой — feature-dev. В обычном мире перезарядка растёт при частых смертях подряд. Точки возрождения по новой карте, у каждой фракции свои.

## Этап 3. Предметы

- [ ] 52. Свойства редких предметов — core-engineer. Ценные вещи меняют работу умений: дополнительный отскок, изменённая область, бонус после уклонения. Редкость должна ощущаться в игре.
- [ ] 53. Наборы экипировки — feature-dev. Бонусы за 2–3 предмета, комплекты можно смешивать. Полный набор не автоматически лучший.
- [ ] 54. Разные материалы для заточки — content-writer. Свои для оружия, брони и украшений, по уровням.
- [ ] 55. Иконки редких предметов — feature-dev. Рамка, свечение, частицы, анимация для высшей редкости.
- [ ] 56. Видимость снаряжения на персонаже — feature-dev. Надетые вещи видны с учётом фракции, улучшенный вид предметов. Чем выше заточка, тем ярче эффекты. Некоторые предметы легендарные должны выглядеть супер особенно, добавить им реально достойные эффекты.
- [ ] 57. Качество маунтов — feature-dev. Детальный вид и анимации; свои маунты у каждой фракции (кони у людей, скелеты коней у нежити).

## Этап 4. Экономика

- [ ] 58. Баланс экономики — core-engineer. Пересчитать как в хорошей MMORPG: золото с лута, цены зелий, заточки, материалов, ремонта, путешествий, торговцев, банка. Золото уходит из игры, цены растут с уровнем. Формулы и таблицы — в BALANCE.md.
