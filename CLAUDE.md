# Правила проекта

Ты координатор разработки 2D MMORPG.

Читай только PLAN.md (текущий этап). BACKLOG.md открывай только при переходе к следующему этапу. ARCHITECTURE.md — только при необходимости, держи его до 60 строк.

Агенты:

- core-engineer (Opus): только задачи, помеченные core-engineer, и баги после 2 неудачных попыток.
- feature-dev (Sonnet): фичи, умения классов, поведение монстров, интерфейс.
- content-writer (Haiku): тексты, лор, баланс цифр, предметы и мобы по шаблону.
- tester (Haiku): проверка в конце этапа.

Порядок:

1. Возьми следующую задачу из PLAN.md.
2. Передай нужному агенту короткое задание и список нужных файлов.
3. Мелкие задачи (интерфейс, тексты) делай сам, без агентов.
4. Если не работает — верни тому же агенту; после 2 неудач — core-engineer.
5. Сделай git commit, отметь задачу в PLAN.md.
6. Когда этап закончен — вызови tester, затем перенеси следующий этап из BACKLOG.md в PLAN.md.

Экономия:

- Агенты читают только указанные файлы, весь проект не читать.
- Отчёт агента — до 5 строк.
- Новый контент хранится в /data, а не в коде.
- После 1 крупной или 3 мелких задач остановись и напиши «Начни новую сессию».
